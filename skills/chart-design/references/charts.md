## Family map: every chart, when it applies, when it does not

### Ranking (RNK)

| Chart | Use when | Not when |
|---|---|---|
| BAR-H (CH-RNK-01) | ranking categories by a single measure; fewer than 12 categories | time series (use CH-TIM-01 LINE); magnitude in natural category order (use CH-MAG-01 COLUMN) |
| ORDERED COLUMN (CH-RNK-02) | ranking with short category names where vertical reads naturally; 8 categories or fewer | long names (CH-RNK-01); natural order (CH-MAG-01) |
| LOLLIPOP (CH-RNK-03) | ranking where bars would overwhelm the page (many rows, light values); editorial pages that want less ink | values very close together (dots overlap visually less than bars separate); natural order (CH-MAG-01) |
| BUMP (CH-RNK-04) | rank order changes over time: who overtook whom; league-table stories where position, not value, is the message | values matter more than positions (CH-TIM-01); more than 8 competitors (lines tangle) |
| DOT STRIP (CH-RNK-05) | compact ranking with minimal ink; scores and ratings on a known scale | readers need the zero anchor (CH-RNK-03); two measures (CH-DST-02) |
| TABLE WITH BARS (CH-RNK-06) | readers need exact values AND instant rank perception; weekly lists where the change column carries the action | more than 10 rows (paginate or aggregate); no exact-value need (CH-RNK-01) |

### Magnitude (MAG)

| Chart | Use when | Not when |
|---|---|---|
| COLUMN (CH-MAG-01) | comparing magnitude across categories that carry a natural order (sites, phases, units); 8 categories or fewer | the message is rank (use CH-RNK-01 BAR-H, sorted); time series (use CH-TIM-01 LINE; columns over time only for few periods) |
| PAIRED COLUMN (CH-MAG-02) | two measures per category: budget vs actual, plan vs forecast; 6 categories or fewer | more than two series (unreadable; use lines or small multiples); long category names (use CH-DST-02) |
| PAIRED BAR (CH-MAG-03) | two measures per category with long labels (plan vs actual, A vs B); natural category order that must be kept (process steps, stages) | ranking is the message (sort and use CH-RNK-01); before/after change (CH-DEV-02) |
| BULLET (CH-MAG-04) | KPI reporting: actual vs target vs poor/ok/good bands; dashboard rows that must survive print (the honest gauge) | no target (plain bar); trend matters more than level (CH-TIM-06 when built) |
| PROPORTIONAL SYMBOL (CH-MAG-05) | magnitudes spanning orders where bars would dwarf the small ones; impressionistic size comparison with exact values printed | precise comparison (areas are read poorly; values must be printed); more than 7 symbols |
| PICTOGRAM (CH-MAG-06) | countable things told in countable marks (people, lots, trucks); audiences who respond to unit metaphors | non-count measures (rates, currency); values needing precision |
| RADAR (CH-MAG-07) | WARN: only when every axis shares one unit and the audience expects a radar; profile shapes across 3-6 same-unit dimensions, 2 series max | different units per axis (the polygon area means nothing); more than 2 series (unreadable overlap) |
| PARLIAMENT (CH-MAG-08) | seats, slots, berths: integer allocations where each unit matters; majority questions: who crosses the middle line | non-integer measures; totals above ~200 (dots become texture) |
| GAUGE (CH-MAG-09) | WARN: only when a dashboard convention demands a dial for ONE number; single watched value with declared bands and target | any multi-metric view (a gauge burns a page on one number); audiences without the dial convention (bullet reads faster) |

### Time (TIM)

| Chart | Use when | Not when |
|---|---|---|
| LINE (CH-TIM-01) | trend over ordered periods; plan vs actual tracking | categorical comparison (use CH-RNK-01 or CH-MAG-01); cumulative progress vs plan (use CH-TIM-02 S-CURVE) |
| S-CURVE (CH-TIM-02) | cumulative progress vs plan over the project timeline; schedule status reporting (the classic planning S-curve) | non-cumulative period values (use CH-TIM-01 LINE); categorical comparison (use CH-RNK-01 or CH-MAG-01) |
| AREA (CH-TIM-03) | one quantity over time where the VOLUME matters (output, throughput, stock); emphasizing magnitude of change, not just direction | comparing several series (use CH-TIM-01; overlapping areas lie); rates or ratios (area implies quantity; use CH-TIM-01) |
| STACKED AREA (CH-TIM-04) | how a growing total splits into components over time; the total AND its composition are both the story | reading exact middle-band values (baselines wander; CH-TIM-01); more than 4 components |
| SLOPE (CH-TIM-05) | year-over-year or before/after across categories; showing who improved, who declined, who crossed whom | more than two periods (CH-TIM-01); many categories (lines tangle; cap at 7) |
| SPARKLINE STRIP (CH-TIM-06) | scanning many metrics for direction at a glance; weekly one-pagers where shape matters, not exact history | comparing magnitudes across rows (each row has its own scale); fewer than 5 points per row |
| CALENDAR HEATMAP (CH-TIM-07) | workload rhythm: deliveries, tickets, tests per weekday across weeks; capacity planning around recurring peaks | non-calendar dimensions (CH-COR-03); single week (a column chart does it) |
| FAN (CH-TIM-08) | forecasts that honestly show their spread; committing to a range instead of a false point estimate | fabricating bands the model never produced; showing only the median (that is CH-TIM-01 with a dashed tail) |
| GANTT (CH-TIM-09) | schedule communication: 4-10 tasks against a period grid; showing done vs remaining per task plus the critical milestone | full CPM networks with dependencies (planning software, not a slide); more than ~10 rows (summarize to work packages) |
| CONNECTED SCATTER (CH-TIM-10) | trajectories: cost vs output, price vs volume, risk vs progress over years; showing that the RELATIONSHIP moved, not just each measure | many entities (CH-COR-01); audiences unfamiliar with the form (it needs a walkthrough) |
| STREAMGRAPH (CH-TIM-11) | WARN: editorial texture pieces where the organic silhouette IS the message; long series where only the total's swell matters | any reading task at all: every baseline wanders by construction; few periods (the silhouette needs length to mean anything) |
| HORIZON (CH-TIM-12) | WARN: dense monitoring walls scanned for where and when, never how much; many series in little vertical space | reading values (folding destroys them by design); audiences who have never seen a horizon chart |
| STEP (CH-TIM-13) | levels that hold between discrete changes: stock, rates, headcount, policies; the timing of the change is the message | continuously varying measures (use CH-TIM-01); cumulative progress (CH-TIM-02) |
| INDEXED LINE (CH-TIM-14) | comparing growth across series with different units or magnitudes; cost escalation, price indices, relative performance since a baseline | absolute levels matter (rebasing hides them; use CH-TIM-01); one series only (an index of one is just a line) |
| EVENT TIMELINE (CH-TIM-15) | milestone communication: what happens when, on one line; kickoffs, gates, energization dates, handovers | tasks with durations and dependencies (CH-TIM-09 GANTT); more than 8 events (split by phase) |

### Part to whole (PTW)

| Chart | Use when | Not when |
|---|---|---|
| STACKED BAR (CH-PTW-01) | how a total splits, tracked across periods or categories; 2 to 4 additive segments | shares only (use CH-PTW-02, 100% stacked); more than 4 segments (aggregate or use small multiples) |
| STACKED BAR 100% (CH-PTW-02) | how the MIX shifts across periods or categories; the key segment's share is the message | the total matters (use CH-PTW-01; 100% hides growth and shrinkage); more than 4 segments |
| PIE (CH-PTW-03) | one dominant share against one or two others, single period; the audience expects a pie and the data survives one (3 slices max) | more than 3 categories (angles are unreadable; use CH-RNK-01); comparing shares across periods (CH-PTW-02) |
| DONUT (CH-PTW-04) | exactly the pie use case, when the surrounding design system already standardizes on donuts; 3 slices maximum, one clearly dominant | more than 3 categories, always; when angle reading matters (the hole removes the angle cue pies rely on) |
| TREEMAP (CH-PTW-05) | a total split across 4 to 12 parts where the big picture beats precision; budget, scope, or inventory composition at a glance | precise comparisons (area is read badly; use CH-RNK-01); hierarchies deeper than one level (out of scope for this entry) |
| WAFFLE (CH-PTW-06) | one share communicated with countable units: 62 of every 100; audiences who distrust abstract charts (units are literal) | multiple shares (stacked bar or pie); shares under 3% (invisible cells) |
| MARIMEKKO (CH-PTW-07) | two composition questions at once: how big is each category, and how does each split; market or spend maps where width = size and height = share | audiences reading it for the first time without a walkthrough; more than 6 columns or 4 segments (it becomes a mosaic of noise) |
| FUNNEL (CH-PTW-08) | pipeline attrition: ordered > shipped > cleared > delivered; conversion reporting with the rate at each step | non-subset stages (waterfall); more than 6 stages (aggregate) |
| SUNBURST (CH-PTW-09) | WARN: only when a 2-level whole must be shown in one figure; hierarchical composition where both levels matter at once | angle comparison across rings (humans cannot); more than 2 levels (unreadable) |
| CIRCLE PACK (CH-PTW-10) | WARN: editorial openers where an organic cluster invites exploration; one-off overviews where precision is explicitly not the point | comparing circle areas (worse than rectangles, much worse than bars); any recurring report (the pack layout shifts as values change) |

### Correlation (COR)

| Chart | Use when | Not when |
|---|---|---|
| SCATTER (CH-COR-01) | how two measures relate across entities; finding the outlier (the point the title talks about) | time is one of the axes (use CH-TIM-01); hundreds of points (labels collapse; use CH-COR-03) |
| BUBBLE (CH-COR-02) | two related measures plus a weight (budget, volume, headcount); the big-and-bad quadrant story: position shows risk, size shows stake | the size measure is decorative (use CH-COR-01); sizes within +/-20% of each other (area differences invisible) |
| XY HEATMAP (CH-COR-03) | patterns across two ordered dimensions: weekday x week, hour x day, section x month; dense grids where a scatter would be unreadable | entity rows with mixed-scale metrics (use CH-TAB-02, column-normalized); exact value lookup as the primary job (a plain table wins) |
| COLUMN + LINE (CH-COR-04) | a volume and a rate that move together over time; capacity vs utilization, output vs quality | two arbitrary series dual-axed to force a story; scales chosen to make the lines cross dramatically |
| HEXBIN (CH-COR-05) | hundreds of points where overplotting hides the density; finding regimes and clusters in a relationship | few points (bins hide what dots would show); reading individual items (bins have no identity) |
| PARALLEL COORDINATES (CH-COR-06) | WARN: analyst-only views for spotting multi-dimensional profiles; finding which items move together across 3-5 measures | general audiences (line crossings read as meaning; they are layout); more than ~12 items (spaghetti) |
| SCATTERPLOT MATRIX (CH-COR-07) | WARN: analyst overview to pick which pairwise plot deserves a real chart; screening 3 measures for relationships in one glance | presenting to any non-analyst (36 tiny axes explain nothing); more than 3 variables in this spec (use small multiples of CH-COR-01) |

### Deviation (DEV)

| Chart | Use when | Not when |
|---|---|---|
| DIVERGING BAR (CH-DEV-01) | signed variance per category: ahead/behind, over/under, surplus/deficit; the zero line is a meaningful reference (plan, budget, target) | sequential deltas that bridge two totals (use CH-FLO-01); all values one sign (use CH-RNK-01; a one-sided diverging bar is a plain bar) |
| DUMBBELL (CH-DEV-02) | before/after per category: backlog W24 vs W28, score last year vs now; spotting the row that moved against the trend | more than two moments (CH-TIM-01); two unrelated measures (CH-DST-02) |
| SPINE (CH-DEV-03) | two-part splits compared across categories; reading which side of a balance each category falls on | more than two parts (CH-PTW-02); parts that do not sum to a meaningful whole |
| SURPLUS/DEFICIT AREA (CH-DEV-04) | balances that swing between surplus and deficit; variance vs plan over time where the sign is the story | all-positive series (CH-TIM-03); two series compared (CH-TIM-01) |
| DIVERGING STACKED (CH-DEV-05) | survey scales: agreement, satisfaction, support; any graded scale with a natural middle to diverge from | scales with a neutral middle level (fold it out first and say so); more than 4 levels (group to 4) |

### Distribution (DST)

| Chart | Use when | Not when |
|---|---|---|
| HISTOGRAM (CH-DST-01) | showing the shape of one distribution: skew, mode, outliers; first look at any new numeric measure | comparing several distributions (CH-DST-04 or CH-DST-09); categorical counts (CH-RNK-01; bins must be numeric intervals) |
| DOT PLOT (CH-DST-02) | two measures per category on one scale: planned vs actual, this vs that; Cleveland dot plot use cases | before/after change (CH-DEV-02 reads direction); one measure (CH-RNK-05) |
| DOT STRIP (CH-DST-03) | small samples where every raw value can be shown honestly; comparing spread and overlap across a few categories | hundreds of points per row (CH-DST-04 summarizes); two paired measures per category (CH-DST-02) |
| BOXPLOT (CH-DST-04) | comparing many distributions compactly; audiences trained on quartiles (analysts, engineers) | general audiences (boxplots are widely misread; CH-DST-03); multimodal shapes (a box hides two humps; CH-DST-08 or CH-DST-09) |
| POPULATION PYRAMID (CH-DST-05) | two groups across ordered bands: age structures, tenure mixes; asymmetry between the two sides is the message | more than two groups (small multiples); bands without a natural order (CH-MAG-03) |
| CUMULATIVE CURVE (CH-DST-06) | service-level questions: what share clears within N days; threshold commitments: X% within Y | non-cumulative frequencies (histogram when built); comparing many populations (small multiples) |
| BEESWARM (CH-DST-07) | every item matters and outliers deserve a name; one pooled distribution where density and gaps are the story | more than ~60 items (CH-DST-01); several categories compared (CH-DST-03) |
| VIOLIN (CH-DST-08) | statistical audiences comparing multimodal shapes that a box hides; the density curve is already computed and declared, with its bandwidth | general audiences (violins are widely misread: prefer CH-DST-04 or; CH-DST-03) |
| DENSITY CURVE (CH-DST-09) | one distribution's shape for a reader who knows what a density is; the curve is already computed and declared, with its bandwidth | audiences who read areas as counts (CH-DST-01); several overlapping curves (small multiples, not overlays) |
| ERROR BARS (CH-DST-10) | estimates that carry a range: durations, forecasts, measurement spread; comparing both level AND uncertainty across categories | ranges are negligible (use CH-RNK-01); full distribution shape matters (boxplot when built) |

### Flow (FLO)

| Chart | Use when | Not when |
|---|---|---|
| WATERFALL (CH-FLO-01) | explaining how a total moved from A to B through named drivers; cost bridges, budget-to-forecast, headcount walks | independent variances with no running total (use CH-DEV-01); more than 7 steps (aggregate the tail) |
| SANKEY (CH-FLO-02) | where things came from and where they went, conserved end to end; sources to routes to destinations in one figure | cyclic flows (sankeys are acyclic by construction); more than ~6 nodes per column |
| NETWORK (CH-FLO-03) | dependency and connection structures: who touches whom; hub-and-spoke risk: the node everything routes through | force-directed layouts (renderer randomness breaks determinism); more than ~15 nodes (structure drowns) |
| CHORD (CH-FLO-04) | WARN: editorial overviews of dense mutual exchange between few nodes; showing that everything trades with everything, not how much | reading any specific flow (ribbon widths at a glance mislead); sparse matrices (a sankey tells it straight) |

### Spatial (SPA)

| Chart | Use when | Not when |
|---|---|---|
| CHOROPLETH (CH-SPA-01) | rates and intensities across known territories; where-is-it-worst questions for map-literate audiences | absolute counts (big areas lie; CH-SPA-02); territories the audience cannot recognize |
| PROPORTIONAL SYMBOL MAP (CH-SPA-02) | absolute counts anchored to places (stock, headcount, backlog); comparing site magnitudes in their geographic context | rates (symbol size reads as amount); more than ~10 symbols |
| ROUTE PROGRESS (CH-SPA-03) | linear infrastructure: pipelines, roads, transmission lines; one glance answers how far along the line are we | non-linear scopes; progress that does not map to distance |
| DOT DENSITY (CH-SPA-04) | spatial concentration where the cluster shape matters; showing crowding that region averages would hide | few items (plot them as labeled symbols); precise counts (dots are for pattern, the key gives scale) |
| FLOW MAP (CH-SPA-05) | origin-destination stories over real geography; corridor volumes: what moves where, how much | more than ~8 flows (spaghetti); flows both directions between the same pair (split or net them first) |

### Table (TAB)

| Chart | Use when | Not when |
|---|---|---|
| STATUS MATRIX (CH-TAB-01) | readiness tracking: systems x stages, packages x gates, sites x milestones; the reader looks up THEIR row | numeric cells (heatmap table when built); more than 8 rows (split by area or paginate) |
| HEATMAP TABLE (CH-TAB-02) | entities compared across metrics with different scales (progress %, punch count, tests left); the reader looks up their row but the pattern should jump out | one shared scale across all columns (use CH-COR-03's global mode); status enums (CH-TAB-01) |
| KPI TABLE (CH-TAB-03) | executive KPI panels: exact number, change, and shape in one row; metrics with different units that must live on one page | rows sharing one unit where bars would rank them (CH-RNK-06); long histories (the trend cell is a shape, not a chart) |
